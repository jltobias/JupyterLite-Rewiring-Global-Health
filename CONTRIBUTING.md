# Contributing

Contributions are welcome when they preserve the project's browser-first, reproducible, privacy-aware design.

For a new notebook:

1. Use synthetic or clearly licensed public data by default.
2. Add data provenance and citation in the notebook.
3. Add the source to DATA_SOURCES.md.
4. Avoid embedded credentials and sensitive individual-level geography.
5. Provide a static fallback for animations/3D where reasonable.
6. Explain JupyterLite limitations and any full-runtime handoff.
7. Keep model assumptions visible.
8. Test the notebook in the JupyterLite build before release.

For operational examples, use only data and environments you are authorized to use.
